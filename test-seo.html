✅ What to Check Manually

1. View Page Source

Right-click on page → "View Page Source"

Look for these in <head> section:

  • ✅ <meta property="og:title">
  • ✅ <meta property="og:description">
  • ✅ <meta property="og:image">
  • ✅ <meta name="twitter:card">
  • ✅ <script type="application/ld+json">
2. Check Structured Data

In page source, find <script type="application/ld+json">

Should contain JSON with:

  • ✅ "@type": "NewsArticle"
  • ✅ "@type": "BreadcrumbList"
  • ✅ "@type": "Organization"
3. Test with Browser Extension

Install: META SEO inspector

Then visit your pages and click the extension icon

ℹ️ Why Google Rich Results Test Fails

⚠️ "URL is not available to Google" is NORMAL for local development!

Reasons:

  • Your site is on local network (10.21.224.146)
  • Google crawler is on the internet
  • Google cannot access internal IPs

Solution: Deploy to public server with domain name, then test again.
